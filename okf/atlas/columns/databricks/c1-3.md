## Answer

Evidence result: partial.

Service policies on MCP services can return ASK, which pauses the tool call until a user approves it. External agents get an MCP URL-mode elicitation link and retry after approval. An identical call is not prompted again for one hour.

## Products

Unity Catalog service policies (ASK decision) on MCP services
