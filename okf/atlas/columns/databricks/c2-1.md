## Answer

Evidence result: partial.

DurableAgentServer keeps run state in a Runtime Store, recovers interrupted runs after worker restarts, lets clients reconnect to stored events and deduplicates by invocation ID. Invocations in one session run in order. Supervisor Agent delegates to up to 50 subagents and tools.
