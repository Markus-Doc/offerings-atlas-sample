## Answer

Evidence result: supported.

MCP services enforce Unity Catalog EXECUTE grants, tool selection, per-call QPM rate limits and service policies on call and on result, including ASK and partner guardrails. Credentials come from HTTP connections. Egress to MCP servers goes through serverless compute and is subject to network policies.

<!-- chunk: products -->
## Products

Unity Gateway MCP services, service policies, HTTP connections, serverless egress control

<!-- chunk: gaps -->
## Gaps

Jailbreak policy runs only on input. No exclusion patterns in tool selection. Policies are Beta. Calls made directly with USE CONNECTION bypass tool selection.

<!-- chunk: options -->
## Options

Use restricted network policies with allowed MCP domains, and attach output side policies for tool results.
