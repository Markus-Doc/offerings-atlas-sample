<!-- chunk: answer -->
## Answer

Evidence result: supported.

Unity Catalog grants decide which models, MCP services, functions, connections and data a user or service principal can call. MCP services support tool selection, and service policies can allow, deny or ask per caller, for example by tool name and OAuth client ID. User authorization scopes limit what an app can do with the user token.

<!-- chunk: products -->
## Products

Unity Catalog grants and GRANT policies, MCP service tool selection, service policies, user authorization scopes

<!-- chunk: gaps -->
## Gaps

Tool selection does not support exclusion patterns. Service policies are Beta and do not apply to Agent Services. Users with USE CONNECTION can bypass MCP tool selection.

<!-- chunk: options -->
## Options

Withhold USE CONNECTION from end users, set explicit tool lists, and test per-caller policies in Log mode before Enforce.
