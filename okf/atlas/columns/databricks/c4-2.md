<!-- chunk: answer -->
## Answer

Evidence result: partial.

Unity Catalog HTTP connections store external credentials (bearer, OAuth M2M, OAuth U2M shared or per user, dynamic client registration) and the proxy injects them, so callers and agent code never hold the token. MCP services use these connections. Legacy Model Serving agents receive short-lived credentials through automatic authentication passthrough. Service principal OAuth secrets can be scoped and live up to 730 days, with one hour access tokens.

<!-- chunk: products -->
## Products

Unity Catalog HTTP connections, MCP services, automatic authentication passthrough (legacy), OAuth M2M secrets

<!-- chunk: gaps -->
## Gaps

Rotation and revocation of credentials stored in HTTP connections are not described. Non-Databricks resources for legacy agents use secrets in environment variables. OAuth secret rotation is a manual create and replace.

<!-- chunk: options -->
## Options

Prefer managed OAuth or per-user OAuth connections, set short OAuth secret lifetimes, and test that tokens do not appear in traces or inference tables.
