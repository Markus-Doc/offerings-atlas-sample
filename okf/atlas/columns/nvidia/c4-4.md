## Answer

Evidence result: supported.

The toolkit adds an OAuth 2.1 authorisation code flow to A2A. The A2A server validates JWTs against JWKS keys and checks issuer, expiry, required scopes and audience. Clients learn requirements from the agent card.

<!-- chunk: products -->
## Products

NeMo Agent Toolkit A2A client and server, server_auth

<!-- chunk: gaps -->
## Gaps

Relies on an external authorisation server such as Keycloak. Trust boundaries beyond scopes and audience are left to the deployer.

## Options
