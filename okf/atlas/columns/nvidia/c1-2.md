## Answer

Evidence result: partial.

The MCP client limits which server tools become workflow functions with include and exclude lists. A2A servers enforce OAuth scopes, and the MCP auth guidance says to scope OAuth2 tokens to minimum permissions.

<!-- chunk: products -->
## Products

MCP client function groups, A2A server_auth scopes

<!-- chunk: gaps -->
## Gaps

Scopes are set per tool list or token, not as a central per-agent policy over connected systems.

<!-- chunk: options -->
## Options

Combine include lists with least-privilege OAuth scopes at each downstream service.
