## Answer

Evidence result: partial.

The toolkit mcp_oauth2 provider obtains OAuth2 tokens per user and stores them separately per user in a configurable backend, with encryption recommended for external stores. Dynamic client registration credentials are cached for a configurable oauth_client_ttl. Security guidance says to keep secrets in environment variables or a secrets manager and rotate them.

<!-- chunk: products -->
## Products

NeMo Agent Toolkit authentication providers (mcp_oauth2, oauth2_auth_code_flow, service account auth)

<!-- chunk: gaps -->
## Gaps

Revocation and whether tokens can reach model context are not described. Rotation is guidance, not a feature.

<!-- chunk: options -->
## Options

Pair with an external secrets manager and test that tokens never appear in prompts or traces.
