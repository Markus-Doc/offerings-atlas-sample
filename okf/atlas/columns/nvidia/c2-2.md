## Answer

Evidence result: supported.

NIM microservices run models on customer infrastructure, including air-gapped sites, so data stays in the deployer environment. Each NIM uses an explicit model profile ID mapped to an NGC version tag. NIM Operator deploys NIMService resources with autoscaling and model caching.
