## Answer

Evidence result: partial.

NGC models are signed with the OpenSSF Model Signing standard and can be verified with the model-signing package. NIM also validates checksums on download. Each NIM ships a machine-readable SBOM.

<!-- chunk: products -->
## Products

NGC model signing, NIM SBOM

<!-- chunk: gaps -->
## Gaps

No model file content inspection or AI BoM for the model itself. Signatures cover a growing set of models. SBOM needs an AI Enterprise entitlement.

<!-- chunk: options -->
## Options

Verify signatures in CI before deployment and scan model files separately.
