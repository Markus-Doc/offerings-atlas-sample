## Answer

Evidence result: partial.

Entra lists every agent that has an Entra Agent ID, and agent sign-ins are flagged in logs. Microsoft says the full inventory, including agents without an Entra identity, now lives in the Agent 365 registry in the Microsoft 365 admin center.

## Products

Microsoft Entra Agent identity platform

<!-- chunk: gaps -->
## Gaps

Entra alone does not discover agents built as plain app registrations or with no Entra identity. Shadow AI discovery depends on Agent 365, which is outside this subject.

<!-- chunk: options -->
## Options

Use the Agent 365 All agents view and audit app registrations used by agents.
