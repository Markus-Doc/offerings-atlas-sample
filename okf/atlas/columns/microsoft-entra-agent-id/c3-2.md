## Answer

Evidence result: partial.

Global Secure Access can proxy Copilot Studio agent traffic from HTTP nodes, custom connectors and MCP server connectors and apply web content filtering, threat intelligence filtering and network file filtering. Conditional Access controls token issuance to MCP servers and APIs per agent identity or blueprint. Microsoft also describes prompt injection detection at the network layer.

## Products

Global Secure Access for agents, Conditional Access for agents

## Gaps

Network forwarding is documented only for Copilot Studio agents and applies tenant-wide through the baseline profile, not per agent. No tool schema validation or per-tool rate limits. Requires Agent 365 licensing.

## Options
