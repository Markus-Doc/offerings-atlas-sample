<!-- chunk: answer -->
## Answer

Evidence result: supported.

Agent identities are created only from blueprints through supported creation channels, with a required sponsor. Access is granted through access packages with up to three approval stages and expiry. Owners and sponsors can disable agents, disabling a blueprint blocks all its agents, and deleting a blueprint cascades a soft delete to child identities with 30-day restore.

<!-- chunk: products -->
## Products

Microsoft Entra Agent identity platform, Microsoft Entra ID Governance for agents

<!-- chunk: gaps -->
## Gaps

Direct permission grants outside access packages have no expiry or review. Cascade cleanup can lag by hours or days. Governance features need an Agent 365 licence with Entra P1 or E3, or Microsoft 365 E7.

<!-- chunk: options -->
## Options

Route all agent access through access packages and monitor audit logs for direct grants.
