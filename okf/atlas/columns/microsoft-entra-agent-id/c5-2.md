## Answer

Evidence result: partial.

ID Protection detects anomalous agent identity behaviour such as sign-in spikes, unfamiliar resource access, failed access attempts, directory reconnaissance and early-life malicious activity. Learning Mode suppresses behavioural alerts for agents with little history.

## Products

Microsoft Entra ID Protection for agents

<!-- chunk: gaps -->
## Gaps

Detections are offline and based on identity and access signals, not task output. In OBO flows risk is attributed to the user, not the agent. Licensing is moving to Agent 365.
