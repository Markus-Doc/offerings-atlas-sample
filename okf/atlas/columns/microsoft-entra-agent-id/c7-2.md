## Answer

Evidence result: partial.

ID Protection produces agent risk detections, a Risky Agents report and Graph collections riskyAgents and agentRiskDetections, exportable to Log Analytics, event hubs or a SIEM. Responders can confirm compromise, which triggers risk-based blocking, or disable the agent. Sponsors are shown on risky agent details.
