How [Microsoft Entra Agent ID](profile.md) addresses the [Agent ID](../../controls/c4-1.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

Each agent gets an agent identity in Entra ID, created from an agent identity blueprint that holds shared description, credentials, permissions and verified publisher. A sponsor is required on every agent identity and blueprint, so each identity is linked to an accountable human. Copilot Studio creates an agent identity automatically for each new agent since May 2026, and Foundry, App Service and Teams also provision them.

<!-- chunk: products -->
## Products

Microsoft Entra Agent identity platform, Copilot Studio Entra Agent ID integration

<!-- chunk: gaps -->
## Gaps

Linkage to runtime and release version is not part of the identity schema. Copilot Studio agents created before May 2026 still use app registrations until migrated. Foundry project agents share a project identity until published.

<!-- chunk: options -->
## Options

Record runtime and release in blueprint description, tags or custom security attributes. Migrate older Copilot Studio agents and confirm the Entra Agent ID GUID in agent metadata.
