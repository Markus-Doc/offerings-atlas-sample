## Answer

Evidence result: partial.

Because a callee agent can be an Entra-protected resource, Conditional Access policies scoped by agent identity, blueprint or custom security attribute decide which agents get tokens for it. Risk policies can block risky agents from reaching other agents.

## Products

Conditional Access for agents, Microsoft Entra ID Protection for agents

## Gaps
