<!-- chunk: answer -->
## Answer

Evidence result: supported.

Agent identities receive scoped access through Microsoft Graph delegated and application permissions, Azure RBAC, Entra roles, app roles, groups and access packages. Entra blocks high-privilege roles such as Global Administrator and permissions such as Application.ReadWrite.All for agents. Conditional Access controls token issuance per agent, blueprint or attribute, and Copilot Studio connector permissions appear as API permissions on the agent identity.

<!-- chunk: products -->
## Products

Microsoft Entra Agent identity platform, Conditional Access for agents, Copilot Studio Entra Agent ID integration

<!-- chunk: gaps -->
## Gaps

Applies only where the downstream system accepts Entra tokens. API keys bypass Conditional Access. Copilot Studio connector scopes are honoured only by the Power Platform connector runtime. Agent Conditional Access needs an Agent 365 licence.

<!-- chunk: options -->
## Options

Front non-Entra systems with an Entra-protected API and grant least privilege through access packages.
