## Answer

Evidence result: supported.

Promptfoo red teaming sends generated adversarial inputs to models, RAG pipelines, agents and MCP or A2A targets and grades the responses. Plugins cover bola, bfla, rbac, ssrf, shell and SQL injection, indirect prompt injection, RAG and memory poisoning, data exfiltration and MCP attacks. Runs can be one-off or in CI/CD, and red team tracing feeds application traces back into attacks.
