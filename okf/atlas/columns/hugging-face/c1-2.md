## Answer

Evidence result: partial.

Fine-grained tokens limit what a client, including an agent, can do against named Hub repositories and organisation features. Service account tokens can be scoped organisation-wide or per repository. The MCP Server only exposes extra tools such as Contribute Repos, Sandboxes and Jobs when a user enables them in MCP settings.

<!-- chunk: products -->
## Products

Fine-grained tokens, service account tokens, MCP Server tool settings, Resource Groups granular feature access

<!-- chunk: gaps -->
## Gaps

Scopes apply to Hugging Face resources only. MCP tool selection is a per-user setting, not an admin-enforced policy.

<!-- chunk: options -->
## Options

Issue each agent a fine-grained service account token. Restrict Jobs and inference features to specific resource groups.
