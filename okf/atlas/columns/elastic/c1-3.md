## Answer

Evidence result: partial.

Custom tools can require user confirmation with never, once or always settings. In the UI this applies to workflow and MCP tools, and through the Tools API to all custom tool types. Confirmation applies only to agent calls, direct Tools API calls skip it, and sub-agents decline confirmation-requiring actions.

## Products

Agent Builder Require user confirmation

<!-- chunk: gaps -->
## Gaps

Generally available on Serverless only, planned for Stack. Bulk-imported MCP tools default to never. Binding to exact arguments and replay handling are not documented.

<!-- chunk: options -->
## Options

Set confirmation to always for write tools and test argument tampering after approval.
