## Answer

Evidence result: partial.

The inference API creates named endpoints with an explicit inference_id for Elastic-hosted models and third-party providers including Bedrock, Anthropic, Azure and OpenAI. Agent Builder uses a default model or a per-request inference_id or connector_id. Agent Builder also routes low-effort tasks to a fast model, which cannot be turned off.
