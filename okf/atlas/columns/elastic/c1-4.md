## Answer

Evidence result: partial.

Custom agents are created, edited and deleted in Agent Builder with Public, Shared or Private access and per-agent User, Editor or Manager grants. Deletion is restricted to the owner, administrators or Managers in 9.5 and later. API keys are created, updated and deleted through the security APIs.

<!-- chunk: products -->
## Products

Agent Builder custom agents, Elasticsearch API keys

<!-- chunk: gaps -->
## Gaps

No approval step or change history for agent creation documented. Defaults differ by version, Public on Stack 9.4 to 9.5.

<!-- chunk: options -->
## Options

Manage agents and keys through the Kibana APIs from a reviewed pipeline, and set Private as standard.
