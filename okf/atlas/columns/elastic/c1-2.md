<!-- chunk: answer -->
## Answer

Evidence result: supported.

A request through Agent Builder must pass Kibana feature privileges, Elasticsearch cluster and index privileges and Kibana space scope. Tools run with the caller's privileges, and API keys cannot exceed their owner's rights. Each agent is assigned only selected tools, and index search tools are limited to named indices or patterns. DLS and FLS further restrict documents and fields.

<!-- chunk: products -->
## Products

Agent Builder permissions, Elasticsearch RBAC, DLS and FLS

<!-- chunk: gaps -->
## Gaps

Scopes on external MCP servers depend on the connector's static credentials. DLS has documented query limits and aggregation leakage.

<!-- chunk: options -->
## Options

Keep per-agent API keys with narrow index patterns, and test DLS against aggregation queries.
