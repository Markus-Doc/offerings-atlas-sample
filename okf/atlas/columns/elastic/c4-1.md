## Answer

Evidence result: partial.

Agent Builder custom agents have a unique agent ID set at creation, and the creating user is recorded as owner. Workloads calling Elasticsearch authenticate with API keys that carry metadata and show the creating user and realm. Neither links an agent to a runtime or release version.

<!-- chunk: products -->
## Products

Agent Builder custom agents, Elasticsearch API keys

<!-- chunk: gaps -->
## Gaps

No release or runtime binding. No agent versioning documented. Agents are not first-class Elasticsearch principals.

<!-- chunk: options -->
## Options

Map each agent to a dedicated API key with metadata naming owner and release, and track releases in an external registry.
