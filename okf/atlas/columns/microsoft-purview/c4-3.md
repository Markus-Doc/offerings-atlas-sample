## Answer

Evidence result: not-addressed.

Purview does not propagate delegated authority. It depends on it: Foundry data security policies apply only to API calls that use an Entra user-context token or explicitly include user context, and Microsoft 365 Copilot prompts run in the initiating user's security context.

<!-- chunk: products -->
## Products

None

<!-- chunk: gaps -->
## Gaps

Delegation is provided by Entra and the AI platform, not Purview. Without user context, Foundry interactions appear only in audit and activity explorer.

<!-- chunk: options -->
## Options

Require user-context tokens or the user security context parameter in Foundry apps so Purview policies apply per user.
