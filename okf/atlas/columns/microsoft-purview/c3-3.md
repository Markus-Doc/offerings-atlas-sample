## Answer

Evidence result: supported.

Purview enforces data access for AI per user and agent: sensitivity labels require VIEW and EXTRACT rights before AI apps return content, DLP excludes labelled items from Copilot responses, and Azure AI Search can enforce labels at query time for RAG apps. DLP policies can scope agent instances and custom apps can call Purview APIs inline.

<!-- chunk: products -->
## Products

Sensitivity labels, DLP for Microsoft 365 Copilot location, Azure AI Search label enforcement, Purview APIs, Endpoint DLP

<!-- chunk: gaps -->
## Gaps

Strongest for Microsoft 365 content. Foundry policy enforcement needs user-context tokens and developer integration. ChatGPT Enterprise and Claude Enterprise agents lack label and DLP support.

<!-- chunk: options -->
## Options

Test label enforcement with a RAG app on Azure AI Search and a DLP policy scoped to an agent instance.
