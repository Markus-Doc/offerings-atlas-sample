## Answer

Evidence result: partial.

DLP can block Copilot and Cowork from using external web search as a grounding source when a prompt contains chosen sensitive information types. Endpoint DLP and network data security can warn or block sensitive data sent to third-party AI sites and apps.

<!-- chunk: products -->
## Products

DLP for Microsoft 365 Copilot location (Performing Web Searches action), Endpoint DLP, network data security

<!-- chunk: gaps -->
## Gaps

Covers web search and AI site egress only. No per-agent tool allow lists, schema checks, auth configuration or rate limits for tools.
