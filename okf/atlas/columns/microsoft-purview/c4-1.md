## Answer

Evidence result: not-addressed.

Purview does not issue or manage agent identities. It consumes them: audit records carry AgentId, AgentName and AgentVersion, and the DSPM AI observability page shows each Agent 365 instance's Entra-enabled status, owner and agent user ID. Identity itself comes from Microsoft Entra.
