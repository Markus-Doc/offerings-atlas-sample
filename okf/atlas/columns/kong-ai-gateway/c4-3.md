How [Kong AI Gateway](profile.md) addresses the [Delegation (OBO)](../../controls/c4-3.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

The AI MCP OAuth2 plugin validates the user's token, then can exchange it as the subject token (with an optional actor token) for a token scoped to the upstream MCP server. It can also forward token claims, including nested claims, to the upstream as headers.

<!-- chunk: products -->
## Products

AI MCP OAuth2 plugin token exchange and claim forwarding

<!-- chunk: gaps -->
## Gaps

Documented for MCP traffic only. LLM and A2A delegation is not described. Requires Kong Gateway 3.14 or later and the AI Gateway Enterprise tier.

## Options
