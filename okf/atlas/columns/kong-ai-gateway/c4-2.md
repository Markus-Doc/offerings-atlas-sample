<!-- chunk: answer -->
## Answer

Evidence result: supported.

Provider and upstream credentials are held in AI Vaults (HashiCorp Vault, AWS, GCP, Azure, CyberArk Conjur or the write-only Konnect Config Store) and resolved by reference at request time, so callers never see the provider key. The AI MCP OAuth2 plugin strips the caller's token before forwarding by default and can exchange it for a different token, cached until its expiry. Changelog 2.2.0 adds Token Vault support for short-lived upstream credentials.

## Products

AI Vault, AI Model Provider, AI MCP OAuth2 token exchange, Token Vault (2.2.0)
