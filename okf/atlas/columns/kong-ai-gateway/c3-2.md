## Answer

Evidence result: supported.

AI MCP Server entities convert REST APIs to MCP tools or proxy upstream MCP servers, validate tool calls against OpenAPI or JSON Schema parameters, enforce per-consumer tool ACLs and inbound OAuth2, and run attached rate limiting and logging policies. Outbound traffic can go through a forward proxy.

<!-- chunk: products -->
## Products

AI MCP Server, AI MCP OAuth2, AI Policies

<!-- chunk: gaps -->
## Gaps

AI Guardrails are listed as not supported on MCP traffic, so tool calls and results are not injection screened. Annotations for destructive tools are hints only. No general internet egress allow list is described.

<!-- chunk: options -->
## Options

Restrict upstream hosts at the network layer and screen tool outputs in the harness.
