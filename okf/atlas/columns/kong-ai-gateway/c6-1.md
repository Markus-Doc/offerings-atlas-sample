## Answer

Evidence result: partial.

Konnect Catalog inventories APIs, AI models, MCP servers with tools, resources, prompts and input schemas, and agents built from A2A cards. MCP server records carry semver versions and npm, PyPI or OCI packages. The MCP Registry adds a publishing and discovery endpoint based on the MCP Registry API specification.
