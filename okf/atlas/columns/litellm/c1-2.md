How [LiteLLM](profile.md) addresses the [Agent Remote Scopes](../../controls/c1-2.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

MCP Permission Management assigns allowed servers at key, team, end user, agent, internal user and organisation level, intersecting the lists so the most restrictive wins. allowed_tools, disallowed_tools and allowed_params restrict tools and their parameters, with 403 on violation. A2A agent access and model access are scoped per key and team in the same way.

<!-- chunk: products -->
## Products

MCP Permission Management, Tool Policies, Agent Permission Management, virtual key model lists

<!-- chunk: gaps -->
## Gaps

Servers marked allow_all_keys bypass per-key grants. Keys with an empty list inherit the team list unless require_key_mcp_access_defined is set.

<!-- chunk: options -->
## Options

Set require_key_mcp_access_defined, avoid allow_all_keys for sensitive servers, and test parameter restrictions with crafted tool calls.
