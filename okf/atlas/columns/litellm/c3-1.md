<!-- chunk: answer -->
## Answer

Evidence result: supported.

Virtual keys enforce allowed models, budgets, TPM, RPM and parallel limits per key, user, team, organisation, agent and customer, with per-model limits. Guardrails run pre_call, during_call and post_call, including built-in prompt injection detection by similarity or LLM check and third-party providers such as Lakera and Bedrock. Per key, team and model guardrail control requires an Enterprise licence.

<!-- chunk: products -->
## Products

Virtual keys, Budgets and Rate Limits, Guardrails, Prompt Injection Detection

<!-- chunk: gaps -->
## Gaps

Budgets need Postgres and fail open without it. Rate limits need Redis to be shared across instances. Several named guardrail integrations need an Enterprise licence.

<!-- chunk: options -->
## Options

Run Postgres and Redis, set default_on guardrails, and test injection detection with a known attack set.
