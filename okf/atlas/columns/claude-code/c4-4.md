## Answer

Evidence result: partial.

Agent teams and subagents exchange messages through SendMessage and local mailbox files. Claude Code tells the receiving agent the message came from another Claude session, a teammate cannot approve permission prompts or relay a denied action, and in auto mode the classifier reviews each inter-agent message before delivery.

<!-- chunk: products -->
## Products

Agent teams (experimental), subagents, cross-session messaging, auto mode classifier

<!-- chunk: gaps -->
## Gaps

Communication is between sessions of the same user on one machine through JSON files. There is no cryptographic authentication of agents or trust boundary definition, and agent teams are experimental and off by default.

<!-- chunk: options -->
## Options

Keep agent teams disabled in managed settings unless needed. For cross-boundary agent communication use an external A2A layer with its own authentication.
