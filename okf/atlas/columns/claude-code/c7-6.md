## Answer

Evidence result: partial.

Official and community marketplace names are reserved for sources under github.com/anthropics, so a third-party marketplace cannot pose as Anthropic's and Claude Code refuses to load one that tries. Archive digests and commit pins block tampered downloads, and allowlists and blocklists gate marketplace sources before download and at session start.

<!-- chunk: products -->
## Products

Marketplace tiers, integrity checks, strictKnownMarketplaces, blockedMarketplaces

<!-- chunk: gaps -->
## Gaps

No scanning for typosquatting, tool metadata poisoning or compromised packages within allowed marketplaces. Auto-update can change reviewed files.

<!-- chunk: options -->
## Options

Allowlist only internal and official marketplaces, turn off auto-update for third-party sources, and set disableSideloadFlags.
