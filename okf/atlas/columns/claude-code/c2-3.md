<!-- chunk: answer -->
## Answer

Evidence result: supported.

Local shell commands run in an OS-level sandbox with filesystem and network isolation and a proxy-enforced domain allowlist. Cloud sessions run in isolated Anthropic-managed VMs with configurable network access, or on customer infrastructure through self-hosted environments. Dev containers and the sandbox runtime can wrap the whole process.

<!-- chunk: products -->
## Products

Sandboxed Bash tool, cloud sessions, self-hosted environments, dev containers

<!-- chunk: gaps -->
## Gaps

The proxy does not inspect TLS by default, so broad allowed domains permit exfiltration or domain fronting. No sandbox on native Windows. Hooks, MCP servers and mods run outside the sandbox.

<!-- chunk: options -->
## Options

Use a custom TLS-inspecting proxy and narrow domain lists, and run the whole process in a dev container for higher-risk work.
