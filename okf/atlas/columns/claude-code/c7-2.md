## Answer

Evidence result: partial.

Administrators can force OTLP export through managed settings so developers cannot redirect it. Every event carries session.id, account, email and organisation IDs, and content is redacted by default. Plugin install and load events support supply-chain monitoring.

## Products

OpenTelemetry export, managed telemetry configuration
