## Answer

Evidence result: supported.

OpenTelemetry exports cost and token counters per model, session and user. Analytics dashboards show accepted lines, accept rate, active users, and with GitHub integration the PRs and lines shipped with Claude Code. Spend reports, the Enterprise Analytics API and the Console Claude Code Analytics API give per-user cost.

<!-- chunk: products -->
## Products

OpenTelemetry metrics, analytics dashboard, contribution metrics, Analytics APIs, modelPricing

<!-- chunk: gaps -->
## Gaps

Cost figures are list-price estimates unless modelPricing is set. Contribution metrics are unavailable with ZDR and for API and cloud-provider usage. Labour savings and profit are not measured.

<!-- chunk: options -->
## Options

Set modelPricing to contracted rates and combine contribution metrics with DORA metrics as the documentation suggests.
