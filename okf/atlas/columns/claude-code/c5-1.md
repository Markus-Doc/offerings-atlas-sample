## Answer

Evidence result: supported.

Users review each proposed edit and command before approval in Manual mode, approve plans in plan mode, and can rewind code and conversation with checkpoints. Code Review runs multi-agent review on pull requests for Team and Enterprise plans.

<!-- chunk: products -->
## Products

Permission prompts, plan mode, checkpointing, Code Review

## Gaps

Auto mode and acceptEdits reduce per-action review. Plan approvals from teammates are granted by the lead without the user.

<!-- chunk: options -->
## Options

Require plan mode for high-risk repositories and keep human pull request review as the final gate.
