## Answer

Evidence result: supported.

CLAUDE.md files at managed, project and user scope carry persistent instructions, and auto memory lets Claude write learnings per repository that load in every session. Subagents can have their own persistent memory directories. A managed policy CLAUDE.md cannot be excluded.
