## Answer

Evidence result: supported.

Claude Code delegates to subagents, runs dynamic workflows and, experimentally, agent teams with a shared task list, dependencies, file-locked task claiming and graceful shutdown. Users can stop a teammate, resume subagents by name, and failed teammates notify the lead with the error.

<!-- chunk: products -->
## Products

Subagents, dynamic workflows, agent teams, task list

<!-- chunk: gaps -->
## Gaps

Agent teams are experimental, cannot be resumed with in-process teammates, and task status can lag. Recovery after failure depends on the lead or user spawning a replacement.

<!-- chunk: options -->
## Options

Use subagents for production automation and treat agent teams as experimental. Use TaskCompleted and TeammateIdle hooks as quality gates.
