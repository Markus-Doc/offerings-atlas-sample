## Answer

Evidence result: supported.

Models are selected by alias or pinned ID, with per-alias pinning on Bedrock, Google Cloud and Foundry. Administrators restrict models with availableModels, enforceAvailableModels and deniedModels, cap effort, and restrict API providers with allowedProviders. Data handling and encryption at rest are documented per provider.

## Products

Model configuration, availableModels, allowedProviders, maxEffortLevel, provider choice

## Gaps
