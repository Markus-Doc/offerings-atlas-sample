## Answer

Evidence result: partial.

The sandbox is enforced by the operating system, cloud sessions run in isolated VMs that are reclaimed after inactivity, and administrators can set a required version range and fail-closed settings refresh. Server-managed settings are a client-side control that a user with a modified binary can bypass.
