## Answer

Evidence result: partial.

Administrators provision configuration centrally through server-managed settings, MDM or managed-settings.json, including managed subagents, force-enabled plugins, MCP servers and hooks, with a required version range. Seats, SSO and SCIM are handled at the Claude account level.

<!-- chunk: products -->
## Products

Managed settings, managed subagents, enabledPlugins, managedMcpServers, requiredMinimumVersion

<!-- chunk: gaps -->
## Gaps

No lifecycle for individual agent identities. Users can still create their own subagents and skills unless strictPluginOnlyCustomization is set. Server-managed settings cannot target groups.

<!-- chunk: options -->
## Options

Combine strictPluginOnlyCustomization with a managed plugin marketplace so agent definitions come only from controlled sources, and use gateway or MDM policies for per-group targeting.
