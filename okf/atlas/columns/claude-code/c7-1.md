## Answer

OpenTelemetry logs carry prompts (opt-in), tool decisions, tool parameters (opt-in) and API requests with session and user attributes. Cloud session operations are logged for audit, settings changes are available through the compliance API or audit export, and the Claude apps gateway records a per-request audit log with IdP identity.
