## Answer

Evidence result: partial.

Commercial data is not used for training, standard retention is 30 days, and Zero Data Retention is available to qualified Enterprise accounts. Local transcript retention is set by cleanupPeriodDays, cloud sessions can be deleted, and residency follows the chosen provider or a gateway that routes inference through the customer's cloud.

<!-- chunk: products -->
## Products

Data usage policy, ZDR, cleanupPeriodDays, Claude apps gateway

<!-- chunk: gaps -->
## Gaps

Auto memory has no documented retention limit. Feedback transcripts are kept for 5 years when users submit them.

<!-- chunk: options -->
## Options

Disable feedback and nonessential traffic in managed settings, set retention, and use ZDR or a provider in the required region.
