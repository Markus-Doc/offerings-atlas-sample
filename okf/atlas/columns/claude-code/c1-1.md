## Answer

Evidence result: supported.

Permission rules allow, ask or deny tools and specifiers such as Bash commands, Read and Edit paths and WebFetch domains, with a working directory boundary and permission modes. The OS-level sandbox (Seatbelt on macOS, bubblewrap on Linux and WSL2) restricts filesystem and network reach of shell commands. Managed settings can lock rules with allowManagedPermissionRulesOnly and disable bypass or auto mode.

<!-- chunk: products -->
## Products

Permission rules and modes, sandboxed Bash tool, managed settings

<!-- chunk: gaps -->
## Gaps

Bash deny rules match command text, not effect. The sandbox does not cover file tools, MCP servers or hooks and is unavailable on native Windows.

<!-- chunk: options -->
## Options

Enforce sandbox.enabled with allowManagedDomainsOnly and managed permission rules, and run on WSL2 on Windows.
