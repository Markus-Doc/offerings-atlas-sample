## Answer

Evidence result: supported.

The Claude apps gateway, built into the claude binary and self-hosted, signs users in with the corporate IdP, enforces model access per IdP group server-side, routes and fails over between Bedrock, Google Cloud, Foundry and the Anthropic API, and caps spend per user, group or organisation with live 429 enforcement. Console workspaces also offer spend and rate limits.

<!-- chunk: products -->
## Products

Claude apps gateway, gateway spend limits, Console workspace limits

<!-- chunk: gaps -->
## Gaps

No documented prompt injection screening at the gateway. Spend enforcement fails open by default if Postgres is unavailable. Caps are USD estimates, not token rate limits.

<!-- chunk: options -->
## Options

Set enforcement.fail_closed_on_error, and add a separate screening layer if injection screening at the model boundary is required.
