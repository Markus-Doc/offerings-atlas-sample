## Answer

Evidence result: partial.

Snowflake CoWork user memory remembers preferences a user asks it to save and uses them in later conversations. Users can turn it off under Settings, which does not delete existing memories. Threads also persist until deleted.

## Products

Snowflake CoWork user memory, Cortex Agents threads
