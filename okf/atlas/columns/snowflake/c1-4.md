## Answer

Evidence result: supported.

Agents are created, altered and dropped with SQL, REST or Snowsight, controlled by CREATE AGENT on the schema, MODIFY to update or drop, and OWNERSHIP transfer. Creating external MCP server objects needs CREATE EXTERNAL MCP SERVER, held by account admins by default. Agent access is granted with USAGE through Snowflake roles.

<!-- chunk: products -->
## Products

Cortex Agents, external MCP server objects, Snowflake RBAC

<!-- chunk: gaps -->
## Gaps

No built-in approval step before an agent or connector goes live. ALTER replaces the full specification.

<!-- chunk: options -->
## Options

Manage agent specs through Git import and CI, and restrict MODIFY and OWNERSHIP to a release role.
