## Answer

Evidence result: partial.

The code execution tool runs Python in a sandbox that can only access data passed into the session and the mounted workspace stage. It cannot query data or reach arbitrary stages, skill stages are read-only, and PyPI packages need the owner to hold PYPI_REPOSITORY_USER. The tool is enabled per agent in the spec.
