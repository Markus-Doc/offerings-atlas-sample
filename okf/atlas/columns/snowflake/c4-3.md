How [Snowflake](profile.md) addresses the [Delegation (OBO)](../../controls/c4-3.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

Cortex Agents determine session permissions from the querying user's default role, and each tool runs with Snowflake privileges for that caller. Cortex Analyst runs generated SQL under the calling role, CoWork applies the user's RBAC and masking policies, and MCP connectors use per-user OAuth to the third-party service. Stored procedure tools keep their owner's or caller's rights setting, and Cortex Search runs with owner's rights.

<!-- chunk: products -->
## Products

Cortex Agents, Cortex Analyst, Snowflake CoWork, MCP connectors

<!-- chunk: gaps -->
## Gaps

The default role is used, not the session role. Owner's rights procedures and Cortex Search break pure user propagation, and the run API can exclude code execution under owner's rights.

<!-- chunk: options -->
## Options

Use caller's rights procedures for custom tools, set user default roles deliberately, and test with a low-privilege user.
