## Answer

Evidence result: partial.

An agent can include an agent toolset that inherits another agent's tools at run time, and the Snowflake-managed MCP server exposes a Cortex Agent as a CORTEX_AGENT_RUN tool to external agents over OAuth. Access needs USAGE on the agent, and the MCP server enforces a maximum recursion depth of 10 invocations.

<!-- chunk: products -->
## Products

Agent toolsets, Snowflake-managed MCP server

<!-- chunk: gaps -->
## Gaps

No A2A protocol support or agent-to-agent trust boundary model is documented. Calls run as the end user rather than as an authenticated calling agent.

## Options
