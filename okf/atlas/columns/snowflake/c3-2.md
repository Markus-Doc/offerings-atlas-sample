## Answer

Evidence result: partial.

Snowflake checks privileges for each tool and checks that an MCP server and its API integration are enabled before every tool call. API_ALLOWED_PREFIXES and external access integrations limit egress, web search must be enabled by an account admin, and the prompt injection guardrail scans tool outputs. The code execution tool can require user permission.
