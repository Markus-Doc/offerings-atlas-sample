## Answer

Evidence result: partial.

Agents are schema objects created with CREATE AGENT, owned by the creating role and listed with SHOW AGENTS. Each agent has committed immutable versions and aliases, which link the object to a release. Agents have no workload identity of their own. They run under the querying user's default role.

<!-- chunk: products -->
## Products

Cortex Agents (AGENT object, OWNERSHIP privilege, agent versioning)

<!-- chunk: gaps -->
## Gaps

No per-agent service identity or credential. Runtime attribution is by calling user and role, not by agent principal.

<!-- chunk: options -->
## Options

Create a dedicated service user and role per agent for automated callers, and tag agent objects with owner and release metadata.
