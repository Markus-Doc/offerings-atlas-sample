## Answer

Evidence result: supported.

Agent and CoWork queries apply the user's RBAC, row access and masking policies. Sensitive data classification tags columns and can drive tag-based masking, AI_REDACT redacts PII in text, and a Trust Center scanner detects sensitive data accessed by agents without masking or row access policies.

<!-- chunk: products -->
## Products

Snowflake Horizon (RBAC, masking and row access policies, classification), AI_REDACT, Trust Center AI Security

<!-- chunk: gaps -->
## Gaps

Cortex Search runs with owner's rights, so retrieval follows the owner's view of the data. AI_REDACT is best effort and limited to US and some UK and Canadian PII.

<!-- chunk: options -->
## Options

Build search services on already masked views and enable the AI Security scanner package.
