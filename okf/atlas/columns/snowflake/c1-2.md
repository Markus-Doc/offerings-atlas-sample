How [Snowflake](profile.md) addresses the [Agent Remote Scopes](../../controls/c1-2.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

Every tool call is bound by Snowflake privileges: the caller needs privileges on the agent and on every object its tools use, and MCP server access does not grant tool access. Inaccessible tool handling can reject a run or drop tools the role cannot use. MCP connectors limit endpoints with API_ALLOWED_PREFIXES, custom tools reach external hosts only through external access integrations, and tool_choice can restrict a run to named tools.

<!-- chunk: products -->
## Products

Snowflake RBAC, inaccessible tool handling, MCP connectors, external access integrations

<!-- chunk: gaps -->
## Gaps

Remote MCP connectors return the server's full tool list, and no per-tool allowlist inside the agent spec is documented for them.

<!-- chunk: options -->
## Options

Use the reject mode, grant per-tool privileges to dedicated roles, and expose only an agent tool on the managed MCP server.
