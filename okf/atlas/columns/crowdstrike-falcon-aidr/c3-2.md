## Answer

Evidence result: partial.

The MCP proxy inspects tool listings, tool inputs and tool outputs with separate rules per checkpoint, and can block, allow or redact. The MCP Validation detector flags tool poisoning and conflicting tool names. Claude Code and Copilot Studio collectors gate tool calls before they run.

<!-- chunk: products -->
## Products

AIDR MCP proxy, MCP Validation and Malicious Skills and Tools detectors, Claude Code and Copilot Studio collectors

<!-- chunk: gaps -->
## Gaps

No allowed tools list, schema validation, auth config, quota or rate limit for tools. The proxy does not inspect non-MCP API calls or general egress.

<!-- chunk: options -->
## Options

Combine with an MCP gateway that holds tool allow lists and an egress proxy.
