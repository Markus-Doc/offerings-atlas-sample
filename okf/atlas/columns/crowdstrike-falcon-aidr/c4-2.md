## Answer

Evidence result: partial.

The Agentic Identity Provider release says agents get no standing credentials and receive short-lived tokens scoped to the minimum access for the minimum time per task. Continuous Identity grants, denies and revokes access on real-time risk. The Copilot Studio collector uses an Entra federated identity credential so no client secret is stored.
