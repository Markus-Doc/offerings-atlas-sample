## Answer

Evidence result: not-addressed.

Wiz does not broker credentials to agents. It detects exposed secrets, for example OpenAI API keys in a vulnerable container or embedded credentials in AI code, and recommends rotation. That is detection of secret exposure, not scoped delivery or revocation.

## Products

None (secret detection in AI-SPM and Wiz Code is adjacent)

## Gaps

No vault, token exchange or keeping secrets out of model context.

<!-- chunk: options -->
## Options
