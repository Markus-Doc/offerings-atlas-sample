## Answer

Evidence result: supported.

Wiz Defend ingests cloud control plane logs, SaaS logs, AI invocation logs and sensor events, and detects AI threats including prompt injection, model exfiltration and MCP server attacks. Detections map to MITRE ATT&CK, the Blue Agent triages them with a verdict, and Wiz Workflows routes response with ownership context. Redaction of prompt content is not documented.

## Products

Wiz Defend, Wiz Runtime Sensor, Blue Agent, Wiz Workflows
