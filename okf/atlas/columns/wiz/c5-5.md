## Answer

Evidence result: supported.

The AI-SPM Agent Inventory View shows each agent's tools and MCP connections to assess its capabilities and blast radius. AI Tool Identification labels whether a tool can read data, change systems or run code, and the Security Graph shows attack paths an exploited agent could follow to identities and data. Coverage depends on what Wiz can discover agentlessly, in code or through the sensor.
