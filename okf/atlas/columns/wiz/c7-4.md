## Answer

Evidence result: supported.

The eBPF Runtime Sensor runs on VMs, containers and serverless containers hosting AI workloads, detects rogue agents and sensitive data exposure, blocks threats, terminates malicious processes and monitors file integrity and image drift. Agentless posture checks cover the cloud AI services and inference endpoints around them. The sensor is an add-on to Wiz Defend.

## Products

Wiz Runtime Sensor, Wiz Defend, Wiz AI-SPM, WizOS

## Gaps

Managed SaaS model runtimes cannot host the sensor, so coverage there is log and posture based.

<!-- chunk: options -->
## Options

Deploy the sensor on self-hosted inference and agent hosts and use AI-SPM for managed services.
