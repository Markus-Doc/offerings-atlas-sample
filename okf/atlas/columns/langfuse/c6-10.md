## Answer

Evidence result: partial.

Project retention deletes traces, observations, scores and media nightly after a set period (Pro, Enterprise, self-hosted EE). Deletion APIs remove traces, projects and accounts. Cloud offers separate US, EU, Japan and HIPAA regions, and self-hosting allows any location. This governs Langfuse's own copy of data, not agent inputs, outputs or memory elsewhere.

<!-- chunk: products -->
## Products

Data Retention, data deletion API, data regions, SDK masking

<!-- chunk: gaps -->
## Gaps

Retention does not cover datasets or audit logs. No permitted-use controls. ClickHouse trace data is not replicated cross-region.

<!-- chunk: options -->
## Options

Set retention per project, mask sensitive fields in the SDK, choose region or self-host, and delete datasets separately.
