## Answer

Evidence result: not-addressed.

Langfuse does not mediate retrieval or apply DLP to agent data flows. Its masking hooks redact telemetry inside the SDK before export to Langfuse, which protects the trace store but not the agent's data access.

## Products

None

## Gaps

Masking applies only to data sent to Langfuse, and no server-side masking is described.

<!-- chunk: options -->
## Options

Use a data gateway or DLP service for retrieval, and configure SDK masking to keep sensitive data out of traces.
