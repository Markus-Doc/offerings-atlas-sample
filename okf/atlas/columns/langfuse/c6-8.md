## Answer

Evidence result: partial.

Prompts are versioned automatically, served by label, and rolled back by moving the production label. Protected labels stop members and viewers changing production (Enterprise, Pro with Teams add-on, self-hosted EE). Audit logs capture prompt changes on Enterprise. Changes to models, tools, permissions and knowledge are not governed.

<!-- chunk: products -->
## Products

Prompt version control, protected labels, Audit Logs

<!-- chunk: gaps -->
## Gaps

No approval step before a label change. Coverage is prompts only.

<!-- chunk: options -->
## Options

Gate label changes through CI using the API and restrict protected labels to release managers.
