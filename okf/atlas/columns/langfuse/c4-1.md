<!-- chunk: answer -->
## Answer

Evidence result: not-addressed.

Langfuse records agent activity as traces with observation types such as agent and tool, but it does not issue or manage agent or workload identities. Names on observations are application-supplied labels.

<!-- chunk: products -->
## Products

None

<!-- chunk: gaps -->
## Gaps

No identity linking an agent to an owner, runtime or release. Observation names and trace version fields are free text set by the instrumented application.

<!-- chunk: options -->
## Options

Use an identity platform for agent identity and pass the identifier into trace metadata or tags so Langfuse traces can be correlated.
