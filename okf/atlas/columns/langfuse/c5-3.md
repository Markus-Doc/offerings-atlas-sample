## Answer

Evidence result: partial.

Langfuse calculates token usage and USD cost per generation from ingested values or model price definitions, with pricing tiers, dashboards by model, tag or user, and cost alerts. It does not cover infrastructure or labour cost, savings or output yield.

<!-- chunk: products -->
## Products

Token and cost tracking, model definitions, custom dashboards, alerts, Metrics API

<!-- chunk: gaps -->
## Gaps

Only model token cost. Reasoning models need ingested counts. Price changes apply only to later generations.

<!-- chunk: options -->
## Options

Export cost via the Metrics API or blob export and join with infrastructure and business data in a BI tool.
