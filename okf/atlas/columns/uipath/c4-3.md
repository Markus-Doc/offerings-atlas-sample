<!-- chunk: answer -->
## Answer

Evidence result: partial.

On UiPath-authenticated channels a conversational agent runs under the user's own identity. Personal connections let an agent call downstream systems such as Outlook, Slack or Salesforce with the user's own connection, with fallback to the shared folder connection. Tool processes must be set to inherit the parent job identity.

<!-- chunk: products -->
## Products

Conversational agents, Integration Service personal connections

<!-- chunk: gaps -->
## Gaps

Personal connections are Public Preview and unsupported for external application token channels. Autonomous and anonymous runs use a robot account, so the initiating user is not propagated. Fallback to a shared connection silently drops the user context.

<!-- chunk: options -->
## Options

Disable shared fallback connections for user-context tools. Test what identity the downstream system logs for a personal versus shared connection.
