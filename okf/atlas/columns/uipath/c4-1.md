## Answer

Evidence result: partial.

Agents are published as versioned solution packages (1.0.0, incremented on each republish) and deployed into Orchestrator folders. At run time a conversational agent executes as the signed-in user on UiPath-authenticated channels, or as an unattended robot account on anonymous channels. The documentation does not describe a distinct workload identity issued to each agent.

<!-- chunk: products -->
## Products

Solutions packages, Orchestrator robot accounts, Serverless robots

<!-- chunk: gaps -->
## Gaps

No per-agent identity linking owner, runtime and release. Audit records the user or robot account, not the agent. A shared robot account hides which agent acted.

## Options
