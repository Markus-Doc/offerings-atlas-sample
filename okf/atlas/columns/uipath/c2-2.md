## Answer

Evidence result: supported.

All LLM traffic goes through the AI Trust Layer gateway. Policies restrict which UiPath-managed providers and models each product can call, can lock current model versions by turning off auto allow, can require bring-your-own model only, and restrict routing regions including Australia. UiPath states data is not used to train third-party models. Studio Web policy caps temperature and tokens per response.

<!-- chunk: products -->
## Products

AI Trust Layer, Automation Ops AI Trust Layer policy, Studio Web policy

<!-- chunk: gaps -->
## Gaps

Custom LLM configurations bypass the Models tab restrictions. Policy changes take up to five minutes to apply.

<!-- chunk: options -->
## Options

Set LLM region routing to Australia and disable auto allow new models. Confirm the region in the audit log Model Location field.
