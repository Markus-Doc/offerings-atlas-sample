## Answer

Evidence result: partial.

Delegate is a desktop agent that acts with the user's access on their machine. Admins can set and lock approval mode, execution mode, screen context, blocked apps and sites, and tool permissions through Automation Ops. Guarded mode limits the agent to a project's allowed files and folders. Robot policies in Automation Ops apply Runtime Analyzer rules that restrict applications and web pages.
