<!-- chunk: answer -->
## Answer

Evidence result: supported.

Agents reach connected systems only through tools configured in Agent Builder, using Integration Service connections scoped to Orchestrator folders with Create and Edit permissions. Folder roles and robot account assignments set what the executing identity can do. Tool guardrails can block or filter tool calls on input and output conditions.

<!-- chunk: products -->
## Products

Orchestrator folders and roles, Integration Service connections, tool guardrails

<!-- chunk: gaps -->
## Gaps

No agent-specific scope beneath the executing identity. UiPath states nothing can give a coding agent less than its identity allows. Connector OAuth scopes are fixed for UiPath public apps unless you bring your own app.

<!-- chunk: options -->
## Options

Use bring-your-own OAuth apps with minimal scopes and dedicated folders per agent. Test a blocked tool guardrail condition.
