## Answer

Evidence result: partial.

Tool guardrails apply log, filter, block or escalate actions to tool inputs and outputs using string, number and boolean rules. Centralized guardrails can apply at tool level. MCP server management is governed by Orchestrator roles, and the MCP OAuth flow fails closed unless dynamic client registration is enabled, with a callback domain allow list. Workflow Analyzer rules restrict allowed packages and activities.

## Products

Tool guardrails, AI Trust Layer policy, Orchestrator MCP roles, Studio Web policy

## Gaps
