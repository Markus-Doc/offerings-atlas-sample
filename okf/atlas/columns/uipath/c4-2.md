<!-- chunk: answer -->
## Answer

Evidence result: partial.

Integration Service connections hold OAuth access and refresh tokens and refresh them automatically, and can reference Orchestrator credential assets resolved at run time and cached for one hour. Orchestrator integrates external vaults (CyberArk, Azure Key Vault, HashiCorp, AWS, Google, BeyondTrust, Delinea). MCP Remote server keys go in Secret assets referenced in headers. Serverless executions get a scoped bearer token per run.

<!-- chunk: products -->
## Products

Integration Service connections, Orchestrator credential stores and assets, MCP Secret assets

<!-- chunk: gaps -->
## Gaps

Rotation is documented only for the HashiCorp AD engine. The docs do not state that secrets are kept out of model context, and custom MCP code receives the bearer token and environment variables directly.

<!-- chunk: options -->
## Options

Use read-only vault stores with vault-side rotation. Test whether connection secrets or tokens can surface in agent traces or prompts.
