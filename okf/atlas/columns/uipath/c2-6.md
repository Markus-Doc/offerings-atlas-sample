## Answer

Evidence result: partial.

Agent memory (preview) offers episodic memory of past cases and feedback, and escalation memory of human resolutions. Memory spaces can be shared across agents, and items can be inspected and deleted in Agents instance management. Customer managed key encryption is set when a space is created.

Agent memory, memory spaces

## Gaps

Preview feature. The memory page does not describe access control or a retention policy. Memory items cannot be edited, only deleted and re-added.
