How [Microsoft Copilot Studio](profile.md) addresses the [Agent Provisioning](../../controls/c1-4.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

Copilot Studio creates the Entra Agent ID when an agent is created, updates its connector scopes on each publish, and deletes it when the agent is deleted. Admins control who can author through the Copilot Author security group, route makers to set environments, and can quarantine agents through the Power Platform API. Create, update, publish, share and delete events are audited.

<!-- chunk: products -->
## Products

Entra Agent ID lifecycle, environment routing, quarantine API, Purview audit

<!-- chunk: gaps -->
## Gaps

Quarantine does not support classic chatbots. Legacy agents use app registrations. Makers rather than admins configure most permissions.

<!-- chunk: options -->
## Options

Combine environment routing, data policies and quarantine automation driven from inventory and audit data.
