## Answer

Evidence result: partial.

The agent inventory gives admins a tenant view of all Copilot Studio and Agent Builder agents, including drafts, with creator, owner, channels, authentication and connectors. This surfaces maker-built agents that IT did not commission.

<!-- chunk: products -->
## Products

Copilot Studio agent inventory

<!-- chunk: gaps -->
## Gaps

Covers only agents built in Copilot Studio and Agent Builder, not other AI tools. Classic V1 agents are excluded. The inventory is preview.

## Options

Pair the inventory with Agent 365 or Defender for wider AI discovery.
