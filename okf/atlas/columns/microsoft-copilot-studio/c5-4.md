## Answer

Evidence result: partial.

Agents can send telemetry to Azure Application Insights, and a Copilot Studio dashboard workbook (preview) shows conversations, latency, exceptions and tool usage. Environment-level telemetry is also available in preview.

<!-- chunk: products -->
## Products

Application Insights telemetry, Copilot Studio dashboard workbook

## Gaps
