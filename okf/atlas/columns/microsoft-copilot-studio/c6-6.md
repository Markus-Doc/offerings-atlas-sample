## Answer

Evidence result: supported.

Copilot Studio adds the agent owner as a sponsor on the Entra Agent ID for traceability and accountability. The inventory records createdBy and the current ownerId, and the creator of each connector operation.

<!-- chunk: products -->
## Products

Entra Agent ID sponsors, agent inventory

<!-- chunk: gaps -->
## Gaps

Some preexisting agents have no sponsor. Reassignment when an owner leaves is not described in Copilot Studio docs.

<!-- chunk: options -->
## Options

Use Entra ID Governance to review sponsors and reassign orphaned agents.
