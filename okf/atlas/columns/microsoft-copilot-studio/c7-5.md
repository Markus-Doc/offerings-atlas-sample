## Answer

Evidence result: partial.

An automatic security scan warns makers before publishing when an agent has no authentication, uses maker-provided credentials or is shared organisation-wide. Real-time risk assessment flags exfiltration risks while configuring knowledge, tools and actions. MCP connectors can go through connector certification to be used across tenants.
