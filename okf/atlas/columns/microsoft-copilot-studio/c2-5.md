## Answer

Evidence result: supported.

Copilot Studio documents three harnesses that decide when to call the model and which tools to run: the GitHub Copilot harness for multistep work with files, skills and memory, the standard harness for rule-based agents and agent flows, and the Copilot chat harness for extending Microsoft Copilot Chat. The harness type is recorded per agent in the inventory.

## Products

GitHub Copilot harness, standard harness, Copilot chat harness
