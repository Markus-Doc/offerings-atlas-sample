## Answer

Evidence result: supported.

Changes take effect only when an agent is published, and publish, update and component changes are audited. Agents move between environments as managed solutions through pipelines or Git with deployment history, and version control supports rollback.

<!-- chunk: products -->
## Products

Publish model, solutions, Power Platform pipelines, Git integration, Purview audit

<!-- chunk: gaps -->
## Gaps

Rollback relies on redeploying an earlier solution version. Model changes through the default upgrade are not release-gated.

<!-- chunk: options -->
## Options

Pin a GA model and deploy only managed solutions through approved pipelines.
