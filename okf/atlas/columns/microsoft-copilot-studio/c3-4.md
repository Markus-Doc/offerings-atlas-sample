## Answer

Evidence result: partial.

Makers can enable, disable or disconnect child and connected agents per main agent. A2A connections run on the custom connector infrastructure, which data policies govern, and skills can be blocked with a data policy.

<!-- chunk: products -->
## Products

Connected agents settings, A2A connections, data policies

<!-- chunk: gaps -->
## Gaps

No admin policy for allowed agent pairs or A2A message schemas is documented. Connected agent use inside an environment has no separate admin control.

<!-- chunk: options -->
## Options

Govern A2A custom connectors with data policies and endpoint filtering, and review connected agents through ALM.
