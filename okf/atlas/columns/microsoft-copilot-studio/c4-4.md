<!-- chunk: answer -->
## Answer

Evidence result: partial.

Agents can call child agents, other Copilot Studio agents in the environment, and external agents over the A2A protocol, Foundry, Fabric and Microsoft 365 Agents SDK. A2A connections authenticate with none, API key or OAuth 2.0 and use the custom connector infrastructure. Microsoft states the maker is responsible for permissions, boundaries and traceability with external agents.

<!-- chunk: products -->
## Products

Connected agents, A2A agent connections

<!-- chunk: gaps -->
## Gaps

No mutual agent identity or trust boundary model is documented. A2A allows no authentication. Foundry, Fabric and SDK connections are preview. Full chat history is sent in A2A metadata.

<!-- chunk: options -->
## Options

Require OAuth 2.0 on A2A endpoints and govern the underlying custom connectors through data policies.
