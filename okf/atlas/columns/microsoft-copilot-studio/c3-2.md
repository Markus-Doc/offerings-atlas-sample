How [Microsoft Copilot Studio](profile.md) addresses the [Tool Gateway](../../controls/c3-2.md) control. Researcher verdict: supported. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: supported.

Data policies block or allow connectors, MCP tools, skills and HTTP per environment, with endpoint filtering for HTTP egress, and the connector runtime revalidates every call. An external threat detection endpoint, including Microsoft Defender, is called before each tool invocation and returns allow or block. Defender real-time protection rules can block tool invocations by detection type per agent.

<!-- chunk: products -->
## Products

Power Platform data policies, endpoint filtering, external threat detection webhook, Microsoft Defender real-time protection

<!-- chunk: gaps -->
## Gaps

External threat detection and Defender protection for Copilot Studio are preview, skip classic agents, are set per environment, and default to allow after a one-second timeout. No per-tool quotas or schema enforcement are documented.

<!-- chunk: options -->
## Options

Enable threat detection in every environment with Block the query as error behaviour, and add Defender custom block rules.
