## Answer

Evidence result: partial.

The GitHub Copilot harness runs each task in a secure sandbox governed by Copilot Studio. Computer use runs on a Microsoft-managed hosted browser, an Entra joined and Intune enrolled Cloud PC pool, or the customer's own machines registered in Power Automate. A2A connections can reach on-premises or virtual network agents through the custom connector infrastructure.

<!-- chunk: products -->
## Products

GitHub Copilot harness sandbox, Windows 365 for Agents hosted browser and Cloud PC pool, Power Automate machines

<!-- chunk: gaps -->
## Gaps

Sandbox isolation, networking and code execution limits are not described. Hosted browser and Cloud PC pool are preview, and the hosted browser is not tenant managed.

<!-- chunk: options -->
## Options

Use Cloud PC pools or dedicated managed machines for computer use and request sandbox architecture details from Microsoft.
