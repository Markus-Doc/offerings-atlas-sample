## Answer

Evidence result: partial.

Data policies can block document uploads, SharePoint and OneDrive, and public website knowledge sources, with endpoint filtering for specific SharePoint sites and websites. Tools default to end-user credentials so retrieval follows user permissions. Agents show the highest sensitivity label of SharePoint sources used in a response.

<!-- chunk: products -->
## Products

Data policies, endpoint filtering, end-user credentials, sensitivity labels for SharePoint knowledge

## Gaps
