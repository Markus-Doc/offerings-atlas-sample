## Answer

Evidence result: partial.

Entra admins can see the connectors an agent may call as API permissions on its Agent ID without opening the Power Platform admin center. The inventory lists each connector operation, whether it is a tool or knowledge, when it can be used, and whether the connection is the user's or the maker's.

<!-- chunk: products -->
## Products

Entra Agent ID API permissions, Copilot Studio agent inventory

<!-- chunk: gaps -->
## Gaps

Custom connectors, MCP servers and REST API tools add no Entra scopes. Inventory capability fields are preview and capped at 200 resources per type.

<!-- chunk: options -->
## Options

Use inventory exports through Azure Resource Graph to build a connector reach view per agent.
