## Answer

Evidence result: supported.

Data policies classify connectors as business, non-business or blocked and can block knowledge sources, HTTP, skills, channels and triggers, with endpoint filtering for HTTP, SharePoint and public websites. Published connector use appears as API permissions on the agent's Entra Agent ID, and the connector runtime revalidates them against data policies on every call. Makers can limit an agent to specific connector operations.

<!-- chunk: products -->
## Products

Power Platform data policies, endpoint filtering, advanced connector policies, Entra Agent ID scopes

<!-- chunk: gaps -->
## Gaps

Conditional Access on agent scopes is enforced only in Teams. Custom connectors, MCP servers and REST API tools add no Entra scopes.

<!-- chunk: options -->
## Options

Apply tenant-scoped data policies with endpoint filtering and review agent API permissions in the Entra admin center.
