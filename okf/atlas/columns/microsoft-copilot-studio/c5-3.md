## Answer

Evidence result: supported.

The Power Platform admin center shows Copilot Credit consumption by environment, agent and user with downloadable reports that include channel, model and tool. Admins set monthly per-agent limits. The Copilot Studio Monitor page has a savings calculator for time and cost saved per run or per tool.

<!-- chunk: products -->
## Products

Copilot Studio capacity management, consumption reports, savings calculator

<!-- chunk: gaps -->
## Gaps

Savings figures come from maker estimates, not measured baselines. Admins can turn off cost savings.

<!-- chunk: options -->
## Options

Record baseline task times before deployment and compare with consumption reports.
