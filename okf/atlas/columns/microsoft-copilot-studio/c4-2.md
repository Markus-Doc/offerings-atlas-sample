How [Microsoft Copilot Studio](profile.md) addresses the [Credential Brokerage](../../controls/c4-2.md) control. Researcher verdict: partial. Verification state: unverified. Agents may retrieve this page on the owner's acceptance of 2026-10-10, a proof-of-concept rule. No evaluator has checked it.

<!-- chunk: answer -->
## Answer

Evidence result: partial.

Agent identity tokens use Federated Identity Credentials held by a Microsoft-owned blueprint, so no tenant user can mint tokens or see a secret. Tool connections use Power Platform connections with end-user or maker credentials. Computer use stores site and app passwords in Power Platform internal storage or a customer Azure Key Vault and fills them at sign-in prompts.

<!-- chunk: products -->
## Products

Entra Agent ID blueprint, Power Platform connections, computer use stored credentials, Azure Key Vault

<!-- chunk: gaps -->
## Gaps

Rotation, expiry and revocation of connection credentials are not described in the Copilot Studio pages. Legacy app registrations can have secrets created by tenant admins. Manual authentication can use client secrets.

<!-- chunk: options -->
## Options

Prefer Entra ID with federated credentials or certificates for manual auth, keep computer use credentials in Key Vault and test revocation behaviour on connections.
