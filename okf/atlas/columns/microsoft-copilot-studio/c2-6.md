## Answer

Evidence result: partial.

Memory, a production-ready preview on the GitHub Copilot harness, keeps a separate store per user per agent in Microsoft-managed storage. Makers turn it on per agent but cannot see user memories. Users can view, change or delete memories in chat or a memory portal, and memories are deleted after 28 days of inactivity.

## Products

Copilot Studio Memory (preview)

<!-- chunk: gaps -->
## Gaps

Preview only and not available on the standard harness. Turning memory off does not delete stored memories. No admin retention or eDiscovery controls are described.

<!-- chunk: options -->
## Options

Leave memory off for regulated agents until admin retention controls are documented.
