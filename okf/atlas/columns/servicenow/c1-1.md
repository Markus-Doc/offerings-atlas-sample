## Answer

Evidence result: supported.

Cowork runs actions inside an isolated virtual environment with file system boundaries, protected credential paths, file type read, write or deny rules and a network allow list, set by administrators per user or group (Brazil). On the instance, ACLs, run-as identity and role masking bound what an agent can do, and Build Agent scripts run only in the target app scope (Brazil).
