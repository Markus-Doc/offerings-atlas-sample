## Answer

Evidence result: partial.

AI agents can run as a dedicated AI user, a User [sys_user] record with the AI user identity type and its own fixed roles (Zurich and Brazil). AI Control Tower registers agents as AI assets with lifecycle, risk and owner roles, and Build Agent registers generated agents there (Brazil). The default identity is the dynamic invoking user, so most agents have no distinct workload identity.

## Products

AI Agent Studio user identity (AI user), AI Control Tower inventory, Build Agent

## Gaps

AI user is optional. No documented binding of an agent identity to a specific runtime or release version.

## Options
