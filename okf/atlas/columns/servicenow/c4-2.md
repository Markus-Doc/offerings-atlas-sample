## Answer

Evidence result: partial.

Cowork can log in to websites with stored credential parameters, and the page says sensitive values are kept out of the chat and the agent's plan (Brazil). A2A and MCP connections use Connection and Credential Alias records, and MCP OAuth 2.1 records hold a token revocation URL (Brazil). Rotation, expiry and storage protection of these credentials are not described on the pages read.

## Products

Cowork stored credentials, Connection and Credential Alias, MCP OAuth 2.1 server records

## Gaps

No documented rotation or expiry. The Cowork page does not say whether the model receives credential values.

<!-- chunk: options -->
## Options

Use OAuth with short-lived tokens where possible and review platform credential store documentation. Test that secrets never appear in execution plans or traces.
