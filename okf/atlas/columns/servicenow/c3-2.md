## Answer

Evidence result: partial.

AI Gateway mediates MCP traffic with global and per-server pause, OAuth 2.1 client registration, a data sensitivity policy, and tool scanning against OWASP MCP Top 10 categories with auto-deactivation of vulnerable tools (Brazil). Cowork blocks outbound traffic except to an allow list, and MCP tools can be allowed, blocked or supervised.

<!-- chunk: products -->
## Products

AI Gateway, MCP Client, Cowork network allow list

<!-- chunk: gaps -->
## Gaps

Gateway covers MCP only. MCP rate limits are not configurable. Per-agent tool policy and logging are not described.
