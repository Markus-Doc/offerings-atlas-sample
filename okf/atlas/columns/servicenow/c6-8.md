## Answer

Evidence result: partial.

Asset owners submit change requests that stewards approve, generating change tasks and a new asset record in onboarding (Brazil). Agent instructions have named versions with revert by switching the active version, model target versions are set per instance or skill, and Build Agent offers approved rollback of its scripts.
