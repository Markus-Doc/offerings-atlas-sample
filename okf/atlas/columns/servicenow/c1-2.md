## Answer

Evidence result: partial.

Agents act on connected systems through tools the builder adds, with each tool's run-as identity and role masking applied (Brazil). MCP tools can be set to allow, block or supervised in the Assistant, MCP Server Console limits exposed tools and fields, and Cowork connector scopes limit actions on a service regardless of the credential (Brazil).

<!-- chunk: products -->
## Products

AI Agent Studio tools, MCP Client, MCP Server Console, Cowork connector scopes

<!-- chunk: gaps -->
## Gaps

The MCP server ACL does not apply when an AI agent uses the server. Scope on external systems otherwise depends on the connection credential.

<!-- chunk: options -->
## Options

Use least-privilege credentials per MCP connection and review tool lists per agent.
