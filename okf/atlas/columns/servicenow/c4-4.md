## Answer

Evidence result: partial.

AI Agent Studio supports the Agent2Agent protocol for external agents and exposes ServiceNow agents as secondary agents through an Agent Card endpoint (Brazil). Inbound calls authenticate with OAuth 2.0 or an API key tied to a service account and an A2A auth scope, attached to the AI Agent A2A API Access Policy. Outbound calls use Connection and Credential Alias records, and ACLs apply to external AI agents.

<!-- chunk: products -->
## Products

AI Agent Studio external AI agents, A2A API Access Policy

<!-- chunk: gaps -->
## Gaps

Exposure is enabled by an instance-wide toggle with no documented per-agent filter. Per-caller authorisation beyond service account roles is not described. The two auth scope names on the setup page disagree.

## Options

Create one service account and OAuth client per partner platform with minimal roles. Test that unexposed agents reject calls.
