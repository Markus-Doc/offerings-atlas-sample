## Answer

Evidence result: supported.

AI Control Tower can require AI steward approval before AI skills, agents and models deploy, and can block unapproved MCP servers in AI Agent Studio, though these controls are off by default (Brazil). AI users are created as User records, ACLs and role masks are set in guided setup, and new instances from the Australia release deny agents lacking explicit ACLs. Agents can be deactivated, and AI Control Tower flags dormant agents holding permissions.
