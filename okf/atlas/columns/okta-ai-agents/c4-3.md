<!-- chunk: answer -->
## Answer

Evidence result: supported.

Cross App Access issues a short-lived ID-JAG carrying the user's identity, which the resource authorisation server exchanges for its own access token under admin policy set in Okta. Agent Gateway exchanges the agent token for downstream tokens on behalf of the user, with first-use consent and stored per-user refresh tokens. A linked app restricts an agent to acting for users currently signed in to that app.

<!-- chunk: products -->
## Products

Cross App Access (XAA), Agent Gateway, Auth0 Token Vault

<!-- chunk: gaps -->
## Gaps

Downstream apps must implement the ID-JAG grant. Delegation chains beyond one hop are not described.
