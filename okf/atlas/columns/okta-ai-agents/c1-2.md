## Answer

Evidence result: supported.

Resource connections bind an agent to authorisation servers, apps, MCP servers, secrets, service accounts or other agents, with scopes set to allow all, only allow or disallow. Deactivating a connection denies all further access requests to that resource. Agent Gateway exposes only admin-selected tools per virtual MCP server.
