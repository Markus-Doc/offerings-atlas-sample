## Answer

Evidence result: partial.

Auth0 for AI Agents offers asynchronous authorisation with CIBA and RAR, so an agent waits for a user to approve an action on a separate device, with Guardian push showing authorisation details. In Okta workforce, approval routing applies to access requests for agent-linked apps, not to individual agent actions.

<!-- chunk: products -->
## Products

Auth0 CIBA and RAR, Okta Identity Governance access requests

<!-- chunk: gaps -->
## Gaps

CIBA needs an Auth0 Enterprise plan or add-on. Binding message, expiry and replay handling are not described on the page read. No per-action approval in the Okta workforce agent product.

<!-- chunk: options -->
## Options

Use Auth0 CIBA with RAR for high-risk actions and test denial and replay behaviour.
