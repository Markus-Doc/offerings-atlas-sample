<!-- chunk: answer -->
## Answer

Evidence result: supported.

Agent Gateway obtains downstream OAuth tokens by STS token exchange and injects them, so the agent never holds tool credentials. Resource connections can hand out secrets and service accounts vaulted in Okta Privileged Access by resource indicator. Auth0 Token Vault stores connected account tokens and refreshes and exchanges them without user action.

<!-- chunk: products -->
## Products

Agent Gateway, resource connections with Okta Privileged Access, Auth0 Token Vault

<!-- chunk: gaps -->
## Gaps

Revoked agent tokens stay valid at the gateway until expiry. Rotation of vaulted secrets and Token Vault encryption are not described on the pages read. The gateway only supports upstreams that accept OAuth bearer tokens.

<!-- chunk: options -->
## Options

Set short token lifetimes, test revocation latency end to end, and use Okta Privileged Access rotation for static secrets.
