## Answer

Evidence result: partial.

Agents are created, updated and destroyed as google_vertex_ai_reasoning_engine resources through the API or Terraform, with identity_type selecting Agent Identity. Agent Identity is derived from the hosting resource, and Agent Registry registers agents automatically from supported runtimes. IAM roles for deployers and runtime principals are listed.

<!-- chunk: products -->
## Products

Agent Runtime, Terraform provider, Agent Identity, Agent Registry

<!-- chunk: gaps -->
## Gaps

Deleting an agent leaves IAM bindings as inactive grants until removed. No approval step for creating or retiring agents.

<!-- chunk: options -->
## Options

Provision through Terraform in CI with review, and add a cleanup step for IAM bindings on deletion.
