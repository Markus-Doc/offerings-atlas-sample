<!-- chunk: answer -->
## Answer

Evidence result: supported.

Agent Gateway is the egress point for agent calls to MCP servers, APIs and agents. It checks IAM access policies (including per-tool CEL rules), verifies the target against Agent Registry, applies Model Armor and semantic governance, and denies requests with no matching policy. Custom authorisation engines can be attached through Service Extensions.

<!-- chunk: products -->
## Products

Agent Gateway, IAM access policies, Agent Registry, Model Armor, semantic governance policies

<!-- chunk: gaps -->
## Gaps

No documented per-tool rate limits or quotas. MCP tools/list and A2A streaming pass without Model Armor sanitisation. Semantic governance is preview.

<!-- chunk: options -->
## Options

Add a custom CONTENT_AUTHZ extension for rate limits. Keep unregistered endpoints denied.
