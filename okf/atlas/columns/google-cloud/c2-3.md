## Answer

Evidence result: supported.

Agent Runtime is a managed container runtime that deploys from images, Dockerfiles or packages, with VPC-SC compliance and Private Service Connect interfaces for private egress. Agents otherwise run in a Google-managed network without VPC access, and internet egress needs a proxy you configure. Agent Sandbox provides isolated code execution, computer use and shell environments.

<!-- chunk: products -->
## Products

Agent Runtime, Private Service Connect interface, VPC Service Controls, Agent Sandbox

<!-- chunk: gaps -->
## Gaps

<!-- chunk: options -->
## Options

Deploy with a PSC interface and a proxy with Cloud NAT inside a VPC-SC perimeter for controlled egress.
