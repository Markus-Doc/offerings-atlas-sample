## Answer

Evidence result: supported.

Online monitors sample live traces on a schedule, score them with predefined or custom metrics such as safety, and write results to Cloud Logging and Monitoring. Offline and simulated evaluation test agents before release. Agent Anomaly Detection analyses reasoning traces and tool interactions for tool misuse, privilege abuse, cascading failures, rogue agents and resource exhaustion, with findings in Security Command Center.
