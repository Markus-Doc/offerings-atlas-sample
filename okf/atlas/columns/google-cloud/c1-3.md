## Answer

Evidence result: partial.

ADK tool confirmation pauses a tool for a yes or no decision or structured input, and the response must match the function_call_id of the confirmation request. A false confirmation returns a rejected status without running the action. Remote confirmation through the REST API is supported, with the invocation ID needed for resumed runs.

## Products

Agent Development Kit tool confirmation

<!-- chunk: gaps -->
## Gaps

Experimental, and not supported with VertexAiSessionService, the managed Sessions service. No approver identity or authorisation check is described. Semantic governance returns only ALLOW or DENY with no escalation.

<!-- chunk: options -->
## Options

Build approval in application code with approver identity checks, or use an in-memory or custom session service until VertexAiSessionService is supported.
