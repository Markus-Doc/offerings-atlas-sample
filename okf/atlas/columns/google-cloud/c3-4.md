## Answer

Evidence result: partial.

Agent Gateway carries A2A traffic and access policies bind calling agent principals to registered destination agents with allow and deny rules. Model Armor screens A2A Send Message operations and agent cards on egress.

<!-- chunk: products -->
## Products

Agent Gateway, IAM access policies, Agent Registry, Model Armor

<!-- chunk: gaps -->
## Gaps

Only MCP traffic gets attribute parsing, so A2A schemas and skills are not enforced. A2A streaming and gRPC are not sanitised.

<!-- chunk: options -->
## Options
