<!-- chunk: answer -->
## Answer

Evidence result: partial.

Agents can act with user-delegated authority through a 3-legged OAuth auth provider: the user signs in and consents, the auth manager stores the tokens in a Google-managed vault, and the agent retrieves them for tool calls. End-user access events are attributable to the agent's SPIFFE ID. Agent Runtime also supports an OAuth client ID per agent for end-user consent.

<!-- chunk: products -->
## Products

Agent Identity auth manager (3-legged OAuth), Agent Runtime

## Gaps

Feature is preview and the IAM Connectors API will not reach GA. No documented propagation of the initiating user identity to Google Cloud APIs or to downstream agents in a chain. Revocation not described.
