## Answer

Evidence result: supported.

IAM access policies enforced by Agent Gateway bind agent principals to registered MCP servers, agents and endpoints with allow and deny rules. CEL conditions can target individual MCP tool names and annotations such as read_only_hint and destructive_hint, and requests with no matching policy are denied. Dry-run mode logs violations before enforcement.

<!-- chunk: products -->
## Products

Agent Gateway, IAM access policies, Agent Registry, Agent Identity

<!-- chunk: gaps -->
## Gaps

Tool-level parsing applies only to MCP traffic. Access policies do not support VPC Service Controls. Only agents routed through the gateway are covered.

<!-- chunk: options -->
## Options

Require agent_gateway_config on all deployments and start in DRY_RUN before ENFORCE.
