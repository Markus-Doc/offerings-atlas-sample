## Answer

Evidence result: supported.

ADK is the fully integrated harness for Agent Runtime, with plugins that run before every agent, model and tool callback and can block tool execution. Prebuilt plugins include Model Armor screening and Tool Call Integrity signing. The Managed Agents API runs agents on the Antigravity harness with sandboxed tools.
