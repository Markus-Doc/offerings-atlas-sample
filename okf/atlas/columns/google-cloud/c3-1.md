## Answer

Evidence result: partial.

Agent Gateway egress covers agent calls to external LLMs, and Model Armor on the gateway screens OpenAI-compatible chat completion, responses and embeddings payloads for injection and data leakage. Organisation policy vertexai.allowedModels restricts which models can be called. Request labels attribute model spend to teams or components.

<!-- chunk: products -->
## Products

Agent Gateway, Model Armor, organisation policy, API call labels

<!-- chunk: gaps -->
## Gaps

Quotas are per project and region, not per agent or user. No documented model routing or rate limiting per agent. Streaming variants are not screened on the gateway.

<!-- chunk: options -->
## Options

Separate agents into projects to approximate per-agent quotas. Use Apigee or a custom gateway for per-consumer rate limits.
