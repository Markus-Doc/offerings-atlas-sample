## Answer

Evidence result: partial.

The Agent Identity auth manager is a credential vault and broker for API keys, OAuth client credentials and delegated end-user tokens, governed by IAM. Agent X.509 certificates renew every 24 hours and Google Cloud access tokens are bound to them, with mTLS and DPoP through Agent Gateway. In the Gemini Enterprise connector path, credentials are decrypted at the gateway so the agent never sees the raw credential.

<!-- chunk: products -->
## Products

Agent Identity auth manager, Agent Gateway, Secret Manager

## Gaps

With ADK on Agent Runtime the token is injected into tool invocation headers inside agent code, and the docs do not state it stays out of model context. Revocation of consent and tokens is not described on the pages read. The 3-legged OAuth page is preview.

<!-- chunk: options -->
## Options

Route tool calls through Agent Gateway so credentials are attached at the gateway. Test that tokens never appear in traces, sessions or prompts.
